# Second brain

This repository uses the [PARA method](https://fortelabs.com/blog/para/) to keep
actionable work separate from ongoing responsibilities and reference material.

## Structure

| Folder | Purpose |
| --- | --- |
| [`1-Projects/`](1-Projects/) | Active work with a defined outcome and end point |
| [`2-Areas/`](2-Areas/) | Ongoing responsibilities and standards to maintain |
| [`3-Resources/`](3-Resources/) | Reference material and topics of interest |
| [`4-Archives/`](4-Archives/) | Inactive or completed content from the other folders |

Put a note where it is useful now. Move it when its role changes rather than
duplicating it across categories.

## Parallel AIC tasks

Personal tasks intended for separate Copilot chats live in
[`1-Projects/AIC-Tasks/`](1-Projects/AIC-Tasks/). Each task is one self-contained
Markdown document named:

```text
AIC-<short-task-name>.md
```

Use lowercase kebab-case for `<short-task-name>`, for example
`AIC-review-backup-plan.md`. See the
[AIC task guide](1-Projects/AIC-Tasks/) for the creation and parallel-chat
workflow.
